# Projeto Front-End: HTML & CSS (Fundamentos e Estrutura)

Este repositório contém um projeto de desenvolvimento front-end voltado para a prática e consolidação dos conceitos fundamentais de **HTML5** e **CSS3**, abrangendo a estruturação de páginas web, sistemas de navegação, formulários, tabelas e estilização moderna.

---

## 🚀 Tecnologias e Conceitos Abordados

* **HTML5**: Marcação semântica, estruturação de conteúdo, links, tabelas e formulários.
* **CSS3**: Estilização visual, seletores de classe/ID, layout e organização de elementos.

---

## 📂 Estrutura e Componentes do Código

### 1. Sistema de Navegação (`<nav>`)
O projeto conta com um sistema de navegação estruturado semanticamente utilizando tags do HTML5:
* `<nav>`: Bloco principal de navegação.
* `<ul>` e `<li>`: Listas para organizar os links do menu (como as seções de "Sonho" e "Expectativa").
* `<a>`: Links de redirecionamento entre páginas e âncoras internas.

### 2. Formulários (`<form>`)
Utilizados para a captação de dados e interação com o usuário (presentes na página de contato):
* `<form>`: Elemento encapsulador dos campos de entrada.
* `<label>`: Rótulos de acessibilidade e descrição para os campos.
* `<input>`: Caixas de texto e campos de preenchimento dinâmico.

### 3. Tabelas (`<table>`)
Estruturação de dados tabulares organizados de forma limpa:
* `<tr>`: Linhas da tabela.
* `<th>`: Células de cabeçalho.
* `<td>`: Células de dados informativos.

---

## 🎨 Principais Comandos e Tags Utilizadas

### No HTML:
* `<!DOCTYPE html>`: Declaração do tipo de documento para HTML5.
* `<meta charset="UTF-8">`: Configuração de codificação para suporte a caracteres especiais e acentuação.
* `<aside>`, `<section>`, `<h1>`: Tags semânticas para hierarquia e divisão de seções visuais da página.

### No CSS:
* **Seletores de ID (`#`) e Classe (`.`):** Utilizados para estilizar elementos específicos e reutilizáveis (ex: `#GUILHERME`).
* **Propriedades visuais:** Controle de fontes, cores de fundo, margens, espaçamentos e alinhamentos de texto.
